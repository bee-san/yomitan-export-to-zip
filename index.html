Yomitan export to ZIP

Turn a Yomitan Export Dictionary Collection file (yomitan-dictionaries-…json) back into standalone dictionary .zip files, numbered in the order they were installed.

Private by construction. Everything runs in this page with JavaScript. Your export is read from disk by your browser and is never uploaded; this site makes no network requests after loading and has no analytics.

1. Choose your export file

In Yomitan: Settings › Backup › Export Dictionary Collection. The file can be very large; it is read as a stream, so it does not need to fit in memory.

2. Order the dictionaries

Archives are named 1-…zip, 2-…zip, … so that importing them in file-name order restores this order. Start from the export order or sort by name; the numbers update as you go.
